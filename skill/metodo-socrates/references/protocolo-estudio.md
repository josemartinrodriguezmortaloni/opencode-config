# Protocolo de Estudio - Checklist Operativo

## Antes de Estudiar un Tema

### Fase de Desmembramiento (15-30 minutos)

Antes de leer CUALQUIER material, completar este proceso:

#### Paso 1: Identificar los 5 Conceptos Fundamentales

Preguntarse: "¿Cuáles son los conceptos tan importantes que sin ellos el tema no existe?"

**Formato de captura:**

```
TEMA: [Nombre del tema]

CONCEPTOS FUNDAMENTALES:
1. [Concepto] - ¿Por qué es fundamental?
2. [Concepto] - ¿Por qué es fundamental?
3. [Concepto] - ¿Por qué es fundamental?
4. [Concepto] - ¿Por qué es fundamental?
5. [Concepto] - ¿Por qué es fundamental?
```

#### Paso 2: Establecer Relaciones

Para cada concepto, definir:
- **Depende de**: ¿Qué conceptos previos necesito?
- **Habilita**: ¿Qué conceptos posteriores desbloquea?
- **Similar a**: ¿A qué se parece de lo que ya sé?
- **Opuesto a**: ¿Con qué no debe confundirse?

#### Paso 3: Clasificar por Jerarquía de Valor

| Concepto | Nivel | Tiempo a Invertir |
|----------|-------|-------------------|
| [C1] | Axiomático / Estructural / Implementación | Alto / Medio / Bajo |
| [C2] | ... | ... |

## Durante el Estudio

### Reglas No Negociables

| Regla | Límite | Razón Biológica |
|-------|--------|-----------------|
| Conceptos por sesión | Máximo 5 | Capacidad de memoria de trabajo |
| Descanso entre conceptos | 20 minutos | Consolidación sináptica |
| Duración máxima de sesión | 90 minutos | Degradación de atención |
| Técnica de estudio | Derivación activa | Activación sináptica requiere esfuerzo |

### Proceso por Concepto

Para cada concepto fundamental:

1. **Leer/Observar** (5-10 min)
   - Primera exposición al material
   - NO tomar notas aún

2. **Cerrar material y derivar** (10-15 min)
   - Sin mirar nada, escribir lo que entendí
   - Intentar derivar desde primeros principios
   - Identificar qué NO entendí

3. **Verificar y corregir** (5 min)
   - Comparar mi derivación con el material
   - Marcar errores y lagunas

4. **Conectar** (5 min)
   - ¿A qué conocimiento previo se conecta?
   - ¿En qué otro dominio aplica este principio?

5. **Descanso activo** (20 min)
   - Caminar, no pantallas
   - Permitir consolidación

## Después del Estudio

### Práctica de Estrés (Obligatoria)

Al finalizar cada sesión, aplicar el test de las 3 métricas:

#### Test de Derivación (Métrica 1)

```
Para cada concepto estudiado:
- [ ] ¿Puedo escribirlo en hoja en blanco sin referencia?
- [ ] ¿Puedo explicar POR QUÉ es así (no solo QUÉ es)?
- [ ] ¿Puedo derivarlo desde un axioma más básico?
```

**Si fallo**: STOP. No avanzar. Volver a los fundamentos.

#### Test de Transferencia (Métrica 2)

```
Para cada concepto:
- [ ] ¿Puedo dar un ejemplo en el dominio original?
- [ ] ¿Puedo dar un ejemplo en un dominio diferente?
- [ ] ¿Puedo dar un ejemplo en un dominio muy distante?
```

**Si fallo**: Buscar más analogías y ejemplos cruzados.

#### Test de Velocidad (Métrica 3)

```
Comparar con sesiones anteriores:
- [ ] ¿Este concepto fue más fácil que el anterior del mismo tema?
- [ ] ¿Pude predecir partes del concepto antes de leerlas?
```

**Si fallo**: Revisar si los fundamentos están sólidos.

## Sistema de Repetición Espaciada

### Configuración de Alarmas

Después de cada sesión de estudio, programar:

| Día | Tipo de Revisión | Formato |
|-----|------------------|---------|
| +1 | Primera derivación | Hoja en blanco, derivar concepto |
| +3 | Segunda derivación | Hoja en blanco + buscar nueva analogía |
| +7 | Tercera derivación | Derivar + transferir a otro dominio |
| +14 | Enseñanza | Explicar a alguien (real o imaginario) |
| +30 | Aplicación | Usar en problema real |
| +90 | Verificación | Test completo de las 3 métricas |

### Formato de Tarjeta de Repaso

**PROHIBIDO**: Tarjetas de recall simple ("¿Qué es X?" → "X es...")

**OBLIGATORIO**: Tarjetas de derivación

#### Estructura de Tarjeta Válida

**Frente:**
```
CONCEPTO: [Nombre]
CONTEXTO: [Situación donde aplica]
PREGUNTA: ¿Por qué [concepto] funciona de esta manera?
         ¿Cómo derivarías [concepto] desde [axioma básico]?
         ¿Dónde más aplica el principio detrás de [concepto]?
```

**Dorso:**
```
DERIVACIÓN:
[Paso 1 desde axioma]
[Paso 2]
[Paso 3]
[Conclusión = concepto]

TRANSFERENCIAS:
- Dominio A: [ejemplo]
- Dominio B: [ejemplo]
- Dominio C: [ejemplo]
```

## Revisión Semestral del Método

Cada 6 meses, responder estas preguntas:

### 1. Retención de Derivación

```
Lista de materias/temas de los últimos 6 meses:
1. [Tema] - ¿Puedo derivar conceptos centrales sin notas? [Sí/No]
2. [Tema] - ¿Puedo derivar conceptos centrales sin notas? [Sí/No]
...

Ratio de retención: ___/___
```

**Si ratio < 70%**: El método de repetición espaciada necesita ajuste.

### 2. Transferencia Real

```
Materias nuevas donde apliqué conocimiento previo:
1. [Materia nueva] ← [Concepto transferido de materia vieja]
2. [Materia nueva] ← [Concepto transferido de materia vieja]
...

Cantidad de transferencias documentadas: ___
```

**Si < 3 transferencias**: No estoy generalizando principios. Revisar Métrica 2.

### 3. Velocidad de Aprendizaje

```
Tiempo promedio por concepto este semestre: ___ horas
Tiempo promedio por concepto semestre anterior: ___ horas

Δt = actual - anterior
```

**Si Δt ≥ 0**: Mi r está cercano a 0. No hay composición. Revisar fundamentos.

## Señales de Alerta Durante el Estudio

### Detener inmediatamente si:

- [ ] Releer el mismo párrafo más de 3 veces
- [ ] No poder resumir lo que acabo de leer
- [ ] Sentir fatiga desproporcionada al tiempo estudiado
- [ ] "Entender" mientras leo pero olvidar al cerrar el libro

### Acción correctiva:

1. Detener el estudio
2. Identificar qué prerequisito falta
3. Retroceder al concepto anterior
4. Derivar ese concepto hasta que pase Métrica 1
5. Solo entonces continuar
